First release of the Rust rewrite of Flare: draw, animate on a timeline with layers, folders, masks, motion tweens and motion guides, work on several documents in tabs, and exchange files with Animate through XFL/FLA import and export. Export PNG and GIF, publish SWF, and drive the same documents from a command line or an AI agent over MCP.

**This is an early alpha.** Expect rough edges and incomplete import fidelity, and keep backups.

Known limits in this release:

- The macOS app is signed ad hoc, not notarised: open it the first time with right-click, Open. The Windows installer is not code-signed, so SmartScreen will ask.
- No shape tweens, only the first scene is edited, there is no scripting (ActionScript in imported files is kept, never run), and keyboard shortcuts cannot be changed yet. Menu entries for these are shown dimmed.
- Text is placed as outlines and is not editable afterwards.
- Guides are not saved with the file, and Outline Mode does not draw mask layers.
- Autosave and crash recovery cover the document being edited, not the other tabs.
- The web build is experimental and not part of this release.
