# Flare

Ein freies Open-Source-Animationswerkzeug im Stil von Adobe Animate, geschrieben in Rust.

> Frühe Alpha: Fehler und unvollständiger Flash/Animate-Import sind zu erwarten. Sichern Sie Ihre Arbeit.
