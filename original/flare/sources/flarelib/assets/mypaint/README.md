# MyPaint brushes

A selection of brushes from the MyPaint brush pack
(https://github.com/mypaint/mypaint-brushes, commit 08da4a48, `brushes/classic`
and `brushes/deevad`), the same pack OpenToonz ships. The brush files are
released under **CC0-1.0** (public domain dedication) by Martin Renold and the
MyPaint Development Team (classic) and David Revoy (deevad); see
THIRD-PARTY-NOTICES.md. File names are `<group>_<name>.myb`.

They are painted by hokusai (pure-Rust libmypaint port, MIT OR Apache-2.0),
pulled in as a crates.io dependency, not copied.
