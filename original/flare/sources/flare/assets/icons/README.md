# Our own icons

`tools/*.svg` are original icons drawn for this project (MIT OR Apache-2.0) in
the style of Flare's tool icons (20 × 20, black shapes on transparent, white
for cut-outs), for tools Flare has no icon for: Pen and the anchor tools,
Pencil, Fluid Brush, Width, Ink Bottle, Gradient Transform, 3D Rotation and
Translation, Magic Wand, the Rectangle/Oval Primitives and the Particle Emitter.
They are not based on Adobe artwork. The toolbar renders them as tinted masks
(`crates/ac-app/src/toolbar.rs`).
