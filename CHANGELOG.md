# Changelog

All notable changes are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - not yet released

The first release of the Rust rewrite. An early alpha: see docs/releases/v0.1.0.md for what it does not do yet.

### Fixed
- File > Open (and a file dropped on the window or given on the command line) opens a picture, a video or another program's project as a new project again, instead of failing with "not a Flare project file": every kind the importer reads is imported, not only `.swf`. Saving such a document asks for a name, and Save never writes a project over the picture or video it came from.
- The start-up splash covers the whole window from the first frame it shows, so the app is not seen before or behind it.
- Playing or rendering an imported `.fla` no longer fails with "cannot be tweened: its matrix has shear or reflection": motion tweens interpolate any 2D matrix (rotation, skew, signed scales, translation), and a tween that cannot be computed holds its keyframe and records a warning instead of blanking the frame.

### Added
- The Magic Wand, in the Lasso's slot as in Animate: a click on a bitmap picks the pixels of a color like the one clicked (Threshold 0 to 200, Contiguous on or off), Shift-click adds and Alt-click takes away, and the picked pixels show striped over the picture. Delete clears them as one undo step, which takes a background off a picture; Invert picks the others to keep only what was picked; Smoothing (Pixels, Rough, Normal, Smooth) sets how soft the edge left behind is. The work runs off the window's thread, so a large picture does not hold it up. `flare magic-wand` (stage points with `--at`, `--keep`, `--dry-run`) and the MCP tool `magic_wand` do the same.
- The Bone tool, as in Animate: a drag from one symbol instance to another links them with a bone, and both move to a new armature layer ("Armature_1") whose keyframes are poses; a drag from an instance already in an armature adds a bone below it. The Selection tool poses an armature: a joint, the instance it carries or a bone (by its tip) is pulled toward the pointer by inverse kinematics, turning the joints above it, and a root moves the whole armature. A pose made between two keyframes is a keyframe of its own that the one before tweens into, and the instances keep playing their symbols through the poses. Properties edits the joint last touched: its turn, its rotation limits, Remove bone and Release armature (back to plain instances, posed). Exports, the preview, SWF and HTML5 show the poses; XFL export writes each pose as its instances, with a warning. `flare bone` and `flare bones`, and the MCP tools `add_bone`, `pose_bone`, `limit_joint`, `detach_bone`, `release_armature` and `list_bones`, do the same.
- Paste puts what was copied into the active layer's keyframe at the playhead, as Animate does, instead of making a layer for each thing; a locked, hidden or guide layer says why it cannot take it. A tween on a keyframe of several elements moves the first and holds the others, in the editor and in imported XFL.
- `.fla` and `.xfl` are first-class save formats, as in Animate, so an animator can work without ever making a `.flare` and send the file on to somebody who uses Animate. File > Save As offers Flash Document (`.fla`, the default), uncompressed Flash Document (`.xfl`, a folder with the `.xfl` inside) and Flare project; the ending of the name decides, and a name with none gets `.fla`. File > Save writes a document back to the file it was opened from, so opening `x.fla`, editing and saving rewrites `x.fla` (the original bytes if nothing changed, otherwise only what was edited rebuilt and every other file of the original kept) and makes no `.flare`. Revert, the Recent list, the tab and window title, the close prompt's Save and autosave all follow the document's file. The file is replaced only by a whole new one, a failed save (read-only file, full disk) leaves the old file and the unsaved work, and a save says what it wrote in the status line and the Output panel: unchanged original, how many files were rebuilt, and what the format cannot hold. In the browser Save and Save As download a `.fla` (or a `.flare` by name). `flare convert` turns any of the three formats into any other, every `flare` project command takes a `.fla` or `.xfl` and edits it in place, `flare new x.fla` makes one, and the MCP server opens them, `save` writes back and `save_as` writes a new file in any format.
- The timeline's frames are small fixed cells, as Animate's are, instead of sharing the panel's width (a short scene's frames filled the whole timeline): empty cells go on to the edge, the zoom changes the cell width, and the Fit button sizes the scene to the panel.
- The tab strip scrolls when there are more documents than fit (the wheel turns it, and a new or chosen tab is brought into view), and its new-document button stays in view however many are open.
- File > Open takes Animate's files as well as Flare projects (`.fla`, `.xfl`, an XFL folder's `DOMDocument.xml` and `.swf`), as Animate's does, so there is no separate import command or Home button. On Linux and Windows the top bar is Animate's: the menus (with a dimmed Debug menu) at the left, Play, Publish and the workspace switcher at the right, then the window buttons; Preferences, undo and redo are in the Edit menu.
- Opening a `.fla`, an XFL folder or a `.swf` and saving it back without changes gives the original back, byte for byte. The file an import was read from is kept with the project (and saved in the `.flare` file), and exporting to its own format while nothing has changed since writes it out as it was; undoing an edit counts as unchanged. After an edit, an export rebuilds only what the edit touched and writes every other file of the original untouched (library bitmaps and sounds, publish settings, metadata, symbols you did not change), and says which. Importing never writes beside or inside the source. `flare import`, `export-xfl` and `publish-swf`, and the MCP tools, report `original_kept`, `lossless` and `original`.
- A legacy binary `.fla` (Flash MX 2004 to CS4) opens from File > Open, `flare import` and `import_project`, in the browser build too, as a skeleton: the stage size, frame rate and background, one empty scene, and the library's symbols as empty graphics, movie clips and buttons, with a warning that drawings, timelines, text and media are not read yet. It was checked against Ruffle's small test files only.
- Everything drawn on a layer stays on that layer, as in Animate: Rectangle, Oval, Line, PolyStar, Pencil, Brush, Pen and Text put their shape in the keyframe of the active layer at the playhead as one more element, a new keyframe starts on a frame that has none, a document with no layers gets "Layer 1", and a locked, hidden, folder, mask, guide or camera layer, or a keyframe that tweens, says why it will not take a drawing. A first drawing in a new document goes into its one layer instead of making a second. Symmetry puts its reflections in the same keyframe. The tool options show Object Drawing (J) dimmed, with a note that Merge Drawing is not built yet. `flare draw-rect` and the MCP `draw_rect` do the same (a layer can be named; `flare info` and `get_info` list each layer's elements).
- A keyframe can hold many elements, as Animate's does: everything on a layer at a frame stays on that layer. The stage, the exports and the frame operations (insert, clear, copy, paste, reverse, convert to keyframes) all see every element; an XFL or FLA keyframe with several shapes keeps them together on one layer instead of spreading them over extra layers, and XFL export writes them in one frame; SWF publishing gives each its own depth. Clicking, Select All and a lasso pick one element at a time, and move, transform, fill, delete, copy, duplicate, convert to symbol, group and break apart act on the elements picked (one undo step); Duplicate and Mirror Copy put the copy in the same keyframe; Modify > Arrange (Bring to Front, Bring Forward, Send Backward, Send to Back) and the Align panel reorder elements inside their keyframe.
- A legacy binary `.fla` (Flash MX 2004 to CS4) opens from File > Import, `flare import` and `import_project`, in the browser build too, as a skeleton: the stage size, frame rate and background, one empty scene, and the library's symbols as empty graphics, movie clips and buttons, with a warning that drawings, timelines, text and media are not read yet. It was checked against Ruffle's small test files only.
- An unpacked XFL project opens from File > Import by picking its `.xfl` file, or its `DOMDocument.xml` when the folder has no `.xfl` beside it; dropping the folder on the window or giving it to `flare open` and `flare import` already worked.
- Closing a document with unsaved work asks "Save changes to ...?" with Save, Don't Save and Cancel, instead of refusing until the work is undone or saved. The timeline draws each frame as a cell, with a keyframe's dot and the box that ends a held keyframe, so frames can be told apart. A right click on the stage opens a menu for what is under the pointer (cut, copy, paste, group, convert to symbol and more).
- The Linux AppImage puts Flare in the desktop menu, with its icon, the first time it runs and whenever the file is moved (`FLARE_NO_DESKTOP_INTEGRATION=1` turns that off). The Windows installer installs for the current user, so it asks for no administrator rights, and the Windows program opens with no console window beside it. `flare-desktop --version` and `--help` answer without opening a window.
- A gradient fill in an imported XFL or FLA document is no longer left out: a two-color linear gradient is drawn as a gradient, and a radial one (or one that does not fit its shape) as one color, with a warning in the Output panel.
- On Linux and Windows the window's title bar is Flare's own top bar, so the document's name is no longer written twice: the bar carries minimize, maximize or restore, and close buttons (close asks about unsaved work), the window moves by its empty space, a double click maximizes it, and it is resized from its edges and corners. `FLARE_SYSTEM_TITLEBAR=1` keeps the system's title bar.
- The whole interface speaks the language chosen in Preferences (English, German, Spanish, French, Brazilian Portuguese, Japanese, Korean and Simplified Chinese): the menus, panels, tools and their hints, dialogs, status messages and the names a new document gives its scene and layer. How long ago a project was opened follows each language's plural rules. The text of errors that come from the libraries is still English.
- When Flare cannot start (no usable graphics device, for one), a message box says why and points to the graphics drivers, instead of nothing happening when it is opened from a launcher.
- Pen pressure on Linux: a tablet pen's pressure shapes the Brush's stroke. It is read from the X server's XInput2 pen axis, so when a pen with pressure is plugged in the window opens through X11 (XWayland under Wayland); `FLARE_TABLET=off` keeps the native window system.
- The Properties panel follows the selection, as Animate's does, instead of having tabs: a selected shape shows its position and size and its fill and stroke, edited on the shape (a color when the picker is let go, a number when it is, one undo step each); a symbol instance shows its symbol, type, Edit Symbol, position and size and looping; several things show their shared position and size; selected frames show the frame and its tween; with nothing selected a drawing tool shows its settings and anything else the document.
- Test Movie plays in a window of its own, with Ruffle running in the same process on the editor's own GPU device, with sound. The picture fills the window, which opens at the movie's own size when the screen has room; under it a bar has a clock and frame at the left, one centered box (Restart, Pause or Play, Step one frame, a playback speed drop-down of 0.25x to 2x, a loop switch that holds the last frame when off, a sound switch) and Close at the right. Control > Test Movie and a right click on the Play button at the top open it. Building without the `ruffle` feature starts an external Ruffle instead.
- With the Subselection tool, a click on a point of the selected shape chooses it (it is drawn filled), and Delete or Backspace takes it out of the outline (one undo step) instead of deleting the shape.
- Timeline: a right-click menu on frames (insert frame, keyframe or blank keyframe, clear keyframe, remove frames, create a motion or shape tween, cut, copy, paste, select all, reverse), Edit > Timeline > Cut Frames and Select All Frames (Ctrl+Alt+X, Ctrl+Alt+A), and Modify > Timeline > Reverse Frames: the keyframes of the selected frames in the opposite order, a tween going with the pair it joined and its easing reversed. `flare frame remove-frames` and `reverse-frames` (with `--to`) and the MCP operations `remove_frames` and `reverse_frames` do the same from scripts.
- The Add (`=`), Delete (`-`) and Convert (`C`) Anchor Point tools, in the Pen's cell: click an outline to put a point there (a curve keeps its shape), click a point to take it out (the outline joins across the gap), click a curve point to make it a corner, drag from a corner to pull out smooth handles. Each is one undo step.
- The status bar shows the stage size and frame rate; a click on them opens the document settings.
- The scene can be renamed by double-clicking its name in the bar above the stage (Enter or leaving the box keeps it, Escape drops it), with `flare rename-scene` and the MCP tool `rename_scene`; the name is trimmed, 1 to 256 characters, and one undo step.
- `flare open [projects...]` starts the desktop app on the given files. The app's program is `flare-desktop` on Linux (`/usr/bin/flare-desktop`) and Windows, so it does not share the name `flare` with the command line on `PATH`.
- A scene can have a camera layer whose keyframes (position, zoom, rotation) and motion tweens change the picture in every render and export; the SWF and HTML5 pages show it too (real Ruffle draws the same picture); `flare camera` and the MCP tool `set_camera` point it; the Camera tool, its Properties and a preview are in the editor; XFL support is still to come (see docs/ROADMAP.md).
- SWF publishing keeps symbols: each becomes a sprite defined once, each instance a placement of it, with the clock its playback says (a looping Graphic and a Movie Clip loop, a Graphic that plays once ends on `stop()`, a held frame is one frame, a Button shows its Up state, and a new span starts the symbol again). Real Ruffle plays the result on the clocks Flare predicts. Tweens are still baked.
- French is an interface language (Preferences > General > Language, and followed from a French system), and the README is translated into every interface language, with a test that keeps the two lists together.
- `flare export --format gif`, and MCP tools `export_gif`, `publish_swf`, `publish_html5`, `export_xfl` and `import_project`: they write into the export directory only, never overwrite, and report what the format could not hold. `flare export --format mp4` and the MCP tool `export_mp4` write the video too, so the command line and MCP server have every export the desktop app has.
- The Polygon lasso (in the Lasso cell): click the corners of a loop, then double-click, press Enter or click the first corner to select what it encloses; Shift adds to the selection and Escape drops the loop.
- `flare-ruffle`'s `embedded` feature runs Ruffle inside the process on a wgpu device it is given: a published movie plays over time into a texture, with sound through Ruffle's mixer (tested: frames advance with the time given, pausing holds, the sound we publish is heard).
- Test Movie works in the browser: the page runs Ruffle's WebAssembly build (`@ruffle-rs/ruffle` 0.7.1, vendored with its licences, fetched on first use) in an overlay over the editor.
- `scripts/build_ruffle.sh` builds Ruffle's desktop player from the pinned checkout, and Test Movie has been run against it (an ignored test opens a published movie in it and checks it keeps playing).
- Ruffle is pinned as a submodule at third_party/ruffle, and `flare-ruffle`'s `render-check` feature has Ruffle's exporter render published SWFs and compares them with Flare's render (solid shapes, a gradient and a mask agree).
- SWF publishing writes linear gradients as gradient fills (matrix placing the first color at the start and the last at the end) and masks of one shape as clip layers; masks of several shapes and masks inside masks are reported and left out.
- SWF publishing writes sounds: each cued sound is defined once as uncompressed 16-bit audio at the nearest SWF sample rate at or above its own, and started at every cue, with scenes offsetting the frames. The total is bounded.
- A document model with scenes, layers (including mask, folder and motion guide layers), frame
  spans, shapes with strokes and gradients, symbols, and sounds. Every change is a validated
  command batch and one undo step.
- Drawing tools: selection, subselection, free transform, lasso, pen, text, line, rectangle,
  ellipse, polystar, pencil, brush, paint bucket, ink bottle, eyedropper, eraser, hand, zoom,
  ruler (measures distance and angle) and mirror (sets the axes for symmetric drawing).
- Shape tweens (Insert > Create Shape Tween) turn one shape into the next, and both tween kinds have Animate's Ease (-100 to 100) in the Properties panel. Tweened spans show an arrow and a color of their own in the timeline. XFL's `tweenType="shape"` and `acceleration` are imported and exported, and `flare frame` has `motion-tween`, `shape-tween`, `remove-tween` and `set-ease`.
- A light theme, chosen in Preferences > General beside Dark, which stays the default.
- The interface can be shown in English, Chinese (Simplified), German, Japanese, Korean, Portuguese (Brazil) or Spanish, chosen in Preferences > General (System locale by default); Preferences and Publish are translated so far, with the rest to follow.
- Publish opens a popup with the formats (Flash, HTML5, animated GIF, and MP4 video with its sound, written by Flare itself in pure Rust) and a Twitter button that opens the post already filled in, and YouTube, Newgrounds and Facebook shown dimmed until they can be filled in too.
- File > Publish writes an HTML5 Canvas page and a Flash movie, as chosen in File > Publish Settings (Loop timeline, Center stage, Make responsive), with sounds started at their cues; `flare publish-html5` does the same from the command line.
- Symbols have a type (Graphic, Movie Clip or Button), chosen when making one or changed in the Library, saved in the project and exchanged through XFL. A Button shows its Up state in the stage and in every export, instead of looping through its frames, and a Graphic instance has Animate's Looping options (Loop, Play Once, Single Frame, and the first frame) in the Object tab, kept in the project and in XFL.
- A Home page at launch: new-project sizes, including a Custom Size card for any width, height and frame rate, Open, Import, and the recent projects as a list with a Filter box and columns for name, date modified, size and kind that sort when clicked.
- Flash movies (`.swf`) open as editable projects: shapes become Graphic symbols, sprites Movie Clips with their own timelines, and the main timeline a layer for each depth, from File > Import, the Home page, the command line, the MCP server or the browser; `.swf` is registered as a file Flare can open on macOS, Windows and Linux, and what a movie holds that Flare does not (text, buttons, pictures, sound, scripts, masks) is listed.
- Text is typed on the stage where it will sit, in the size it will have, and stays text: click it with the Text tool or double-click it to edit the words, and change its font, size and style in Properties, which lists the fonts installed on the machine with a filter box. A text object remembers its words and font in the project file, moves and scales with its place, becomes plain outlines when Modify > Break Apart is used (or when it is turned, sheared or stretched), and is set and edited the same way from `flare add-text`, `set-text`, `break-text` and `fonts` and from the MCP server.
- Preferences with Cmd+, (Ctrl+, elsewhere) in the Flare menu on macOS, and an About window with links to GitHub and Discord.
- The Brush has a nib (Round or Square, with an angle and a flatness) that shapes the stroke; the
  nib and size are kept between sessions. New, choose and Delete keep named custom brushes, and the Brush shows its nib as an outline at the pointer. A brush stroke drawn with smoothing at 0 does not cross itself in slivers, so it does not jump when the pointer is released. Strokes, lines, rectangles and ovals stay on screen from the moment the pointer is let go until the picture that includes them arrives, so nothing flashes.
- Pencil and Brush can draw a straight line (option, or hold Shift) and mirror each stroke across
  one or two axes; Modify > Transform > Mirror Copy makes a reflected copy of the selection.
- Timeline (Control > Go to End, and the comma and period step a frame as in Animate) with frames, keyframes, layers, folders, onion skin, linear motion tweens and motion
  guides, and playback with sound.
- Panels that dock and move: tools, properties, color, align, transform, library, history, output. The tool strip groups related tools in slots as Animate does (press and hold, or right-click, for the list; Subselection, Oval, PolyStar and Ink Bottle are in their slots' lists), with the tools Flare has not built shown dimmed. It scrolls when it is taller than its panel, so the color box can always be reached, and the black-and-white and swap buttons stay where they were at the corners of the color squares, with No color in each color picker so a shape can have no stroke. The strip is one tool wide by default, runs the full height of the window and is a bar of its own. The stage shows its zoom once, in the stage bar. A dimmed Interface switcher sits at the top right, where Animate has its workspace switcher. A Publish button sits beside Play in the top bar. Tools can be dragged from the dots list into the strip and are kept. A layer is renamed by double clicking its name in the timeline, and a right click on it opens a menu of what can be done to the layer. Undo and redo bring back pictures already drawn without drawing them again.
- Several documents in a window as tabs, Open Recent, Save All, autosave and crash recovery,
  Preferences.
- Files: the `.flare` project container (a SQLite file whose records are compressed binary: about a seventh the size of the text it replaces), XFL/FLA import and export, PNG and GIF export (GIF frames are made on several cores), and SWF
  publish. Flash fixtures are tested against.
- The `flare-cli` command line (inspect, render, convert) and an MCP server for agents.
- Text menu: bold, italic, larger and smaller for new text.
- An Info panel (selection size and position, color under the pointer).
- Guides pulled out of the rulers, with snapping; Modify > Timeline > Convert to Keyframes.
- Layer outline colors (timeline chip, `.flare` and XFL) and View > Outline Mode.
- Window, Help (About, Keyboard Shortcuts) menus that do something; Insert > New Symbol; Edit > Paste in Place (Paste now centers on the stage).
- An experimental web build, which opens and saves `.flare` files (SQLite and zstd as WebAssembly) as well as importing Animate files.
- File > Export > Flash Document writes a `.fla` Animate can open.
